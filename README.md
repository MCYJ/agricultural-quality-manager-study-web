# Agricultural Quality Manager study website

Standalone Korean/English prelaunch information site for RushLabs’ independent Korean Agricultural Products Quality Manager study app.

- Questions are in Korean; this website offers Korean and English guidance.
- The exam guide refers to the checked 2026 notice. Future exam arrangements are not confirmed here.
- Store download buttons are disabled, indexing is disabled, and no price or completed bank count is advertised.
- The illustration explains the planned study approach and is not an app screenshot.
- No account form, analytics, tracking, external font or app question bank is included.

```sh
npm test
npm run preview
```

The build uses the dedicated GitHub Project Pages base path. The deployment workflow sets `PUBLIC_SITE_URL` to `https://mcyj.github.io/agricultural-quality-manager-study-web/`.

Website: https://mcyj.github.io/agricultural-quality-manager-study-web/ko/ · English: https://mcyj.github.io/agricultural-quality-manager-study-web/en/

The website is hosted on GitHub Pages. App store release remains in preparation.
